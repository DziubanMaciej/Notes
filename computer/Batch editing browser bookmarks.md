This is neded in an event of domain change, where all relative links stay the same. 

# Firefox
In Firefox there are two options: backup/restore (json file) or import/export (html file). Json file is better because it replaces current bookmarks when restoring. Importing from html appends them to "Bookmarks menu" and you have to manually move them.
1. Bookmark manager (Ctrl+Shift+O) --> Import and backup --> Backup --> Save json file
2. Find&replace the json file
3. Bookmark manager --> Import and backup --> Restore --> Choose file --> Lode json file

# Chrome
In Chrome there's only import/export (html file). I haven't tested how it works. But it's the only option anyway.

# Windows 1.0 (1985)
The program was named `PAINT.EXE`. It was originally written by ZSoft Corporation for MSDOS as PC Paintbrush and later adapted for Windows 1.0.
- No zoom functionality
- No text size selection
- Monochromatic (fun fact, original ZSoft's PC Paintbrush had 4 colors)
- Drawing in patterns
- Close to no keyboard shortcuts
- 1x undo memory with shift+escape shortcut
- The canvas had a size of an A4 paper, but you couldn't see it all.

# Windows 2.0 (1987)
No major changes. The biggest change was the new form of the .msp format. It was incompatible with the old one and existing images had to be converted to the new format with `CVTPAINT.EXE` utility.

# Windows 3.0 (1990)
Renamed to `PBRUSH.EXE`, it was PC Paintbrush licensed again from ZSoft.
- Multiple colors, but still dithering needed to achieve more colors. Sliders for color selection.
- Undo with ctrl+z
- Support for .bmp and .pcx formats

# Windows NT (1993)
Paintbrush from Windows 3.0 was ported to Windows NT.

# Windows 95 (1995)
Complete rewrite, renamed to `MSPAINT.EXE`, initially called Raster.
- Nice color picker
- text transparency, font size
- edge dragging for canvas resize
- MFC based interface

# Windows 98 (1998)
No major visible changes. Introduced support for .png, .jpg and .gif formats in plugins

# Windows XP (2001)
Similar graphical interface.
- GDI+ based interface
- integration with digital cameras and scanners
- true color, no more dithering
- 3x undo
- .png, .jpg and .gif support without plugins

# Windows Vista (2007)
Minor changes
- Interface redesign, new icons
- 10x ctrl+z instead of 3x

# Windows 7 (2009)
A big overhaul
- ribbon interface
- artistic brushes
- shape patterns
- 50x ctrl+z
- drawing tablet

# Windows 10 (2015)
No meaningful changes
- Meant to be killed in 2017 in favor of paint3d

# Windows 11 (2021)
- AI
- Visible brush size sliders
- Dark mode
- Layers support, albeit questionable
    - no opacity
    - no moving layers
    - no custom format (flatten on save)
